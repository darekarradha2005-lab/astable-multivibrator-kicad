# Astable Multivibrator using BJT

## Overview
This project presents the design of a BJT-based Astable Multivibrator using KiCad. An astable multivibrator is a free-running oscillator that continuously switches between two states, generating a square-wave output without requiring an external trigger.

## Objectives
- Design the schematic of an Astable Multivibrator circuit.
- Create the PCB layout using KiCad.
- Understand transistor switching and RC timing networks.
- Gain hands-on experience in PCB design and routing.

## Components Used
- NPN Transistors (2)
- Resistors
- Capacitors
- Power Connector
- LED (Optional)

## Tools Used
- KiCad

## Features
- Continuous square-wave signal generation
- Simple transistor-based design
- Custom PCB layout
- Suitable for learning electronics and PCB design fundamentals
